Home automation system

Implemented a home automation system that integrates over 150 smart devices from various ecosystems into a unified control hub using a Raspberry Pi server. This setup allows for the management of lighting, security, climate control, and entertainment systems through a single interface. I configured automated routines, voice control, and remote access to enhance convenience and efficiency, transforming the home into a responsive environment tailored to daily needs.

Built & modified a 3D printer

Installed an Ender 3 v2 3D printer and undertook several upgrades to enhance its capabilities. First, Also, added a CR Touch for automatic bed leveling, which significantly improves print accuracy and reduces the need for manual adjustments. Next, I upgraded to a Direct Drive extrusion system, allowing the printer to handle a wider range of materials, including flexible filaments, with greater precision. Additionally, I installed an extra Z-axis to stabilize the printer's movements, resulting in smoother and more reliable prints. These enhancements collectively improve the printer's performance, making it more versatile and efficient for various 3D printing projects.

Auto tracking camera

Developed a camera attachment designed to track and follow faces in real-time. This project involved integrating a camera with a motorized mount, which I programmed to detect facial features using computer vision algorithms. The system continuously adjusts the camera's position to keep the detected face centered in the frame. This setup can be used for various applications, such as enhancing video calls, improving security systems, or creating interactive installations. By combining hardware and software components, I created a responsive and dynamic camera system capable of real-time face tracking.

An invisible mouse

Developed a program that transforms a standard camera into an invisible mouse by detecting the position of a hand and using it to control the cursor. This project involved implementing computer vision techniques to accurately track hand movements in real-time. I utilized algorithms to identify the hand's position and gestures, translating these into cursor movements on the screen. This innovative approach eliminates the need for a physical mouse, offering a hands-free and intuitive way to interact with a computer. The invisible mouse can be particularly useful for accessibility purposes, gaming, and creative applications where traditional input devices may be limiting.
